## 模型规则

完整规则见 [`docs/model.md`](docs/model.md)，接口见 [`docs/interfaces.md`](docs/interfaces.md)。核心约定：

- 进程 1–4 个，资源类型 1–3 类，数量为非负整数；不考虑抢占与故障。
- `need = max − allocation`，为派生量，不单独存储。
- 请求处理顺序：输入校验 → 尚需量 → 可用量 → 试分配 → 安全性检查 → 提交或回滚。
- 拒绝原因分三类：`EXCEEDS_NEED`、`EXCEEDS_AVAILABLE`、`UNSAFE_AFTER_TRIAL`，不得合并成「资源不足」。
- 安全性检查使用 `max` 假设；实际死锁使用当前请求做归约，两者独立。
- 每类资源满足 `available + Σallocation = total`。
